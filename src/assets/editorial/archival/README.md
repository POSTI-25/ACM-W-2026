# Editorial engravings

Revised direction: restrained scientific and cultural editorial illustration in deep burgundy, coordinated with the existing engravings in the parent directory.

## New assets

- `camera-engraving.webp` — Gallery introduction. 1254 × 1254. Suggested display width 160–240px.
- `microscope-engraving.webp` — Women in STEM or a research-focused editorial passage. 1199 × 1312. Suggested display width 140–220px.

Both are original artwork created with the built-in image-generation tool. Both have genuinely transparent backgrounds. Export preserved each original alpha channel exactly. Exact prompts, dimensions and file sizes are in `manifest.json`. `engraving-preview.webp` compares them with existing artwork.

## Existing assets to pair with them

- `../quill-inkwell.png` — Blogs and writing.
- `../drafting-compass.png` — Events and ideas.
- `../scientific-orbital.png` — Science and discovery.

Use a single illustration beside a short editorial passage or behind oversized typography, with generous negative space. Keep page imagery focused on the existing real event photographs and portraits.

The proposed photo mount, torn caption paper, tape and brass clip were removed from this collection following the revised direction.
